# fracasso

Registro da sessão de trabalho no projeto **core-sistema**.

## Ideia do projeto

Criar um jogo de RPG. O objetivo é sair do zero: definir o tipo de RPG, a
ambientação e a stack, e evoluir em ciclos curtos de teste.

## O que foi feito

- Criado/atualizado o `README.md` com a explicação do objetivo do projeto.
- Criado este arquivo (`fracasso.md`) para registrar o que foi discutido.

## Pontos em aberto

- Tipo de RPG: mesa/tabuleiro digital, RPG de texto, 2D/3D ou MMO?
- Ambientação: fantasia medieval, cyberpunk, pós-apocalíptico...?
- Stack: Python, JS/TS, Godot, Unity...?
- Qual será o primeiro protótipo testável?
